## 🚀 How to Run Locally

You can open `Portfolio.html` directly in your favorite browser (Chrome, Edge, Firefox, Safari) by double-clicking it, or run the included zero-dependency Node server:

```bash
# Start local server
node server.js
```
Then visit: [http://localhost:3000/Portfolio.html](http://localhost:3000/Portfolio.html)
